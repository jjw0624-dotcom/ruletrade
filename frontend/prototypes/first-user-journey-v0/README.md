# RuleTrade first-user journey prototype

Disposable, static usability-test prototype for the complete first-time journey:

`Enter → Explore → Strategy → Test → Understand → Why → Change → Compare → Why different?`

Run:

```bash
cd frontend/prototypes/first-user-journey-v0
python3 -m http.server 4173
```

Open `http://127.0.0.1:4173`.

Direct research states are available at `#templates`, `#strategy`, `#results`, `#why`, `#change`, `#compare`, and `#differences`. Use **Reset test** to return to a clean first-time state.

This folder does not call RuleTrade APIs and does not define a production contract. All results, traces, comparisons, and candidate edits are deterministic prototype-local fixtures.
