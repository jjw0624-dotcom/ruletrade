## Completion order

1. Summary: comprehensive but progressive projection, capability and latest-result facts.
2. Rules: complete maintained edit coverage through typed operations/CAS, read-only unsupported rows.
3. Flow: capital conservation and route diagnostics while preserving draft-only arbitrary connections.
4. Code: explicitly read-only semantic source with revision/hash/capability/provenance/evidence metadata.
5. Guide: actual strategy walkthrough, missing-input explanation and navigation.
6. AI: keep as an unavailable external handoff; no parallel model or semantic authority.
